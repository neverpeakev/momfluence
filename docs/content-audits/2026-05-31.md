## 3. Pattern analysis

### Critical: variety mono-culture across three axes simultaneously

1. **content_format mono-culture.** 11 of the last 12 published posts are tagged `anecdote`. The thesis defines 5 formats explicitly so the brand has texture variety; we are using 20% of the available range.

2. **City repetition.** All 3 posts this week open with **"A regular mom in Sacramento"**. Going back further: most recent anecdotes name Sacramento as the city. Claude cannot see the previous city choices — only angle tags and headlines are surfaced in `buildUserPrompt`. The pattern is invisible to the generator.

3. **Image background mono-culture.** All 3 posts this week use `warm-gradient`. 10 of the last 12 use `warm-gradient`. The other approved backgrounds (`coral`, `navy`, `cream`, `navy-coral-gradient`, `white-coral-ring`) are effectively unused.

4. **Display structure repetition.** All 3 displays follow the rhythm "**She [verb] / [object]**". Reader cadence across the page becomes monotonous on the feed.

5. **Accent badge homogeneity.** All 3 are dollar amounts in $260–$560 range. Visually identical chips. The schema allows `$5`, `50%`, etc. — unused.

### Voice / vocabulary

- Voice compliance is **strong** — no newsroom drift, no corporate copy, no pain-point openers.
- One vocabulary miss: `zimk2` never says "products and services" — only "recommendations." Minor. Acceptable.
- No dead-phrase hits. BLOCKLIST is holding.

### Caption length

All 3 captions are 140–210 words. Within the 80–300 target. Healthy.

### Why this is happening (root cause)

`buildUserPrompt` in `lib/social/post-generator.ts:312` surfaces recent angle tags and recent display headlines to discourage repetition. It does **not** surface:
- recent `content_format` choices (so Claude can't see the format mono-culture forming)
- recent cities used in anecdotes (so Claude reaches for "Sacramento" again)
- recent `image_bg` choices

The SYSTEM_PROMPT also doesn't impose a hard variety floor on format rotation — it merely lists the 5 formats as available textures.

## 4. Decision: prompt tune (refinement, not pivot)

The v5 voice is locked and **not** being changed. The tune is purely about portfolio-level variety enforcement. Specifically:

### Edits to `lib/social/post-generator.ts`

1. **`SYSTEM_PROMPT`** — Add a new "VARIETY FLOOR" section that requires the generator to:
   - Avoid any `content_format` that appears 2+ times in the recent list. If `anecdote` was the last 2 posts, pick from `{direct, math, brand-callout, objection-reframe}`.
   - For `anecdote` posts: do NOT reuse a city from the recent list. The list of recent cities will be surfaced.
   - Vary `image_bg` — don't reuse the same bg as the most recent post.
   - For `display`: avoid copying the syntactic rhythm of the most recent display (e.g., "She [verb] / [object]" three weeks running).

2. **`buildUserPrompt`** — Extend the inputs to surface recent `content_format` distribution, recent anecdote cities, and recent `image_bg` values. The variety floor is unenforceable if Claude can't see the history.

3. **`GeneratorInputs`** interface — Add `recentContentFormats: string[]`, `recentCities: string[]`, `recentImageBgs: string[]`. (Callers in `/api/social/fb-daily-generate` will need to pass these; that's out of scope for this PR but the prompt is ready.)

4. **`PROMPT_VERSION`** — Bump `2026-05-13.v5` → `2026-05-31.v6`. v6 is a variety-floor tune, not a voice change.

### Edits to `docs/product-thesis.md`

5. Add a "Variety floor" section under "Content formats" documenting that the audit caught a format-mono-culture episode and that the prompt now enforces format/city/bg rotation.

### Edits NOT being made

- No BLOCKLIST additions. No new dead phrases slipped through.
- No voice changes. "Regular moms / big bucks / find out more / get yours" all holding.
- No pivot. The 3 posts this week individually scored 4.8–5.0 against thesis.
