## Pattern analysis

### 1. Format monoculture (persistent, week 2)

The generator has collapsed onto `anecdote`. Every rationale in
`generation_metadata` this week references keeping "the 'she named
the ___' visual rhythm going." That's a self-reinforcing template
loop: the recent-headlines feedback signal is being read as "this is
what we do here," not "this is what we've overused."

The v6 tune in PR #188 adds an explicit `# FORMAT ROTATION (HARD RULE)`
section that forbids >2 of any format in a 5-post window and tells
Claude how to infer format from the `recentDisplays` list it already
sees. That is the correct shape of the fix.

### 2. Headline template monoculture (persistent, week 2)

`"She named the [OBJECT] / at [PLACE]."` — 7 / 7 this week. Combined
with last week, the last 14 published Facebook posts have all followed
this display syntax. A mom seeing three of these in her feed sees the
same shape three times. This is worse for reach than for score, but
it's worse.

PR #188 marks the template "spent for 10 posts" and lists 6
alternative display structures. That fix works as long as it ships.

### 3. Image-background monoculture (persistent, week 2)

Six-value `image_bg` enum. Two-week hit distribution:

| bg | count |
|---|---|
| `warm-gradient` | 13 |
| `cream` | 1 |
| `coral` / `navy` / `navy-coral-gradient` / `white-coral-ring` | 0 each |

PR #188 addresses this with `# IMAGE VARIETY`. Same story: fine once
merged.

### 4. City repetition — new this week

Cincinnati appears in 3 of 7 anecdotes (08-12, 08-14, 08-15). Last
week had Fort Wayne ×2 and Sacramento ×2. The generator has no signal
in its prompt about recently-used cities. This is a **new** finding
not addressed by PR #188 — but small, and best folded into #188
before merge (add "cities used in the last 7 days" to the anecdote
guardrails list) rather than opened as a separate PR.

### 5. Fake-mom / fake-payout anecdotes at scale — soft FTC risk

Every anecdote this week invents a specific mom in a specific city
with a specific dollar payout ($54, $164, $310, $340, $340, $610,
$612). The thesis says: *"Never quote $/day or $/week as a promise —
only show worked examples."* These read as testimonials, not worked
examples. If the FB Page runs enough of these, the reader model
becomes "moms in this program routinely make $310 a week from three
texts" — which is exactly the earnings-claim shape FTC 16 CFR §255
polices.

This is a **thesis-level question** and not something the audit
should silently prompt-tune around. Flagging for human decision:
either (a) reframe anecdotes as clearly hypothetical ("Say a mom in
Tulsa..."), or (b) add a footer disclosure, or (c) reduce anecdote
frequency and lean on `direct` / `brand-callout` formats which don't
carry the same risk. This is one more reason format rotation matters.

### 6. Dead-phrase absence — good

Zero BLOCKLIST hits across all 7 posts. The BLOCKLIST is doing its
job. No additions proposed this week.

### 7. Caption length — good

Range 118–252 words. All well within the 80–300 window and readable
on mobile.

## Decision

**No new prompt-tune PR opened by this audit.** The proposed change
is [PR #188]; opening a second draft would fragment review and
duplicate the touch scope. This audit ships as a scorecard-only PR
titled *"Weekly content audit 2026-08-16 (no changes needed — see
#188)"* to keep the visibility contract with the human reviewer.

**Two things I want the founder to decide this week:**

1. **Merge, reject, or amend PR #188.** The pattern the tune targets
   is still active. Every day it sits unmerged is another anecdote
   with the same headline template.
2. **Fake-mom anecdote framing (finding #5 above).** Soft FTC risk
   that the v6 tune does not touch. Worth an explicit call.

If PR #188 is amended before merge, folding in the city-repetition
guardrail (finding #4) would take it from covering last week's
patterns to covering this week's too.
