## Pattern analysis

### 1. Format monoculture (CRITICAL)

The thesis (docs/product-thesis.md §"Content formats") explicitly states:
"The MESSAGE is fixed. The variation across posts is the FORMAT in which
we deliver it." We are not varying. Direct, math, brand-callout, and
objection-reframe formats — half of the variety axis — went zero-for-the-week.

A follower scrolling Momfluence's page sees the same texture every
single day: regular-mom-in-[city] told another mom about [product],
got paid $XYZ. By post 3 the reader has learned the shape and starts
skimming. The "huh, really?" beat the thesis demands depends on the
news landing fresh — same texture = stale news.

### 2. Display-headline template lock-in (CRITICAL)

All six displays start "She told [the mom ...] / [about the thing]."
The slash + scene + recommendation is one specific microformat that
Claude has decided is the headline pattern. The thesis lists eight+
locked openers (Moms:, Heads up moms:, Did you know, Wait —, POV:,
Hot tip:, Quick PSA:, Anchored moment) and none of them appeared this
week. Visual rhythm on the page is monotone.

### 3. Angle-tag suffix lock-in (mild)

Every angle_tag this week ends `-rec`:
`back-to-school-supply-list-rec`, `target-dressing-room-jeans-rec`,
`gym-daycare-water-bottle-rec`, `hotel-lobby-snack-rec-vacation`,
`sephora-checkout-mascara-rec`, `drive-thru-coffee-order-rec`. The
angle_tag dedup check passes because each slug is unique — but
semantically they're all "mom in [place] makes [product] rec". The
diversity guard is not catching same-shape angles with different nouns.

### 4. Payout number clustering (mild, not actionable)

$280 / $312 / $340 / $340 / $530 across the four anecdotes that had
payouts. All clustered $280–$530, the kind of "believable single-rec"
amount. Not promised (just illustrated), so FTC posture is fine, but
the audit notes it for the human reviewer: the system is converging
on a narrow numeric range.

### 5. Visual: image_bg / accent_badge

Every post used `image_bg = "warm-gradient"`. Six in a row. The schema
offers six choices (coral, navy, cream, warm-gradient, navy-coral-gradient,
white-coral-ring) and Claude picked the same one six times. Same visual-rut
problem as the format collapse. accent_badge usage was reasonable (4 of
6 had dollar badges, varied amounts).

### 6. Dead phrases / blocklist

Zero hits. The BLOCKLIST and "DEAD phrases" sections are doing their
job — the issue this week is variety, not voice slippage.

### 7. Caption length distribution

All captions 150–230 words. Within target band (80–300). Good.

## Decision

**Prompt tune warranted.** The prompt currently lists the five formats
with examples but provides no rotation discipline. Claude has discovered
that anecdotes are the easiest format to write well — concrete person +
place + number is a reliable shape — and has settled there. Without
explicit rotation pressure, this will continue.

**Voice is NOT being changed.** This is a v5.x adjustment, not a voice
pivot. The locked vocabulary, openers, dead-phrase list, and canonical
message are untouched. v6 adds *rotation* constraints on top of the v5
voice.
