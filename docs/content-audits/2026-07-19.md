## Pattern analysis

1. **Root cause of format monotony:** the generator receives
   `recentAngleTags` and `recentDisplays` but **not the recent
   `content_format` values.** So Claude has no signal that the last
   6 posts were all anecdotes — from its POV each generation is a
   fresh coin-flip weighted by whatever texture "feels right." Anecdote
   is the highest-status format in the v5 examples, so it wins every
   time.

2. **Secondary cause:** the SYSTEM_PROMPT tells Claude the message is
   fixed and format is the variety axis, but does not tell Claude to
   *actively rotate* formats or to *avoid the format most recently
   used*.

3. **Template fatigue is visible in the rationales themselves.** From
   07-18: *"keeps the 'She named the ___ / in the ___' visual pattern
   while introducing a specific product."* Claude is explicitly self-
   reinforcing the template rather than breaking it. It has learned
   that reuse of the visual scaffold is a feature. It isn't.

4. **Invented-number fatigue.** $312 recurring 4× across 5 days is
   both boring and slightly suspicious (a reader who sees two of these
   would notice). The prompt's math example uses $720; without a
   nudge, Claude anchors to a single "plausible" number and reuses it.

5. **No dead phrases slipped through.** BLOCKLIST is doing its job.
   No additions warranted this week.

6. **Angle-tag variety is fine** (6 distinct slugs, 6 distinct scenes).
   The variety failure is one level up — at the format and template
   layer.

7. **Caption length distribution:** 130–210 words. Healthy for FB.
   One post (07-13) has no paragraph breaks; that's a formatting bug
   the schema doesn't catch — worth a soft prompt hint but not urgent.

## Decision — prompt tuning warranted

Yes. Non-negotiable at 6/6 anecdote. Bumping to `2026-07-19.v6` with:

- A new **"FORMAT ROTATION IS MANDATORY"** section in SYSTEM_PROMPT
  that explicitly names format monotony as a failure mode and
  instructs Claude to (a) infer the recently-used format from the
  recent headlines list, (b) pick a *different* format for this post.
- A new **"BREAK VISUAL-TEMPLATE REPETITION"** rule: if the recent
  headlines list shows the same syntactic scaffold (e.g., "She named
  the X / in the Y") used 2+ times, this post's headline MUST use a
  structurally different form.
- A new **"VARY THE NUMBERS"** rule: if the recent displays or
  captions clearly reuse a specific dollar figure, pick a different
  one. Never anchor on a house number.
- An optional `recentFormats` field on `GeneratorInputs`. Kept
  optional so existing callers (`app/api/social/fb-daily-generate/
  route.ts`, `scripts/test-post-generator.ts`) continue to compile.
  A follow-up PR should have `recentForContext` populate it from
  `generation_metadata.content_format` — that's outside this audit's
  scope per the guardrails.
- No BLOCKLIST additions this week — individual voice is clean.
- No docs/product-thesis.md tenet changes; just a small note added
  under "Content formats" pointing to the enforced rotation rule.
