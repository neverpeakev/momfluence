## Pattern analysis

### Findings

1. **Format monoculture (severe).** 7/7 posts are `anecdote`. Zero direct, math, brand-callout, or objection-reframe. Founder-facing risk: the feed reads as one long tone.
2. **Dollar-figure repetition (severe).** 6/7 posts use exactly `$340`. The one variation is `$180` on 07-26. Recycling the same number across manufactured anecdotes reads as fabricated and undercuts the "specific > general" tenet.
3. **Display-template repetition (severe).** 6/7 displays follow `"She named the ___ at the ___"`. Post 1 is the only slight break (`in the flu shot line`), and even that fits the pattern. Visual rhythm on the feed is homogenous.
4. **Location repetition (moderate).** Sacramento (3), Columbus (2), Ohio (1), Grand Rapids (1). Sacramento specifically anchors 3 different products in 7 days.
5. **Image_bg monoculture (severe).** 6/7 posts use `warm-gradient`. Only 07-26 broke to `navy-coral-gradient`.
6. **Recurring "three moms bought it" beat.** 5/7 captions include a variant of "three moms wrote it down / ordered it / bought them." Feels manufactured.
7. **Opener drift.** Only post 4 uses a locked opener ("Moms:"). The other 6 dive straight into anecdote. Voice compliance is still 4/5 because the body itself is conversational, but the smart-friend-texting energy is diluted.
8. **New blocklist candidates:** none rise to must-add. "If you've ever texted…" in post 4 is worth watching but I don't want to over-index on one instance.

### Positives

- **Canonical delivery is bulletproof.** Every post has the news + eligibility puncture + CTA. Zero misses.
- **Vocab hygiene is strong.** "regular moms," "real money," "get your cut," "find out more" all landing correctly. Zero dead-phrase hits on the automated blocklist.
- **Rationales are honest.** Every rationale acknowledges the "she named the ___" rhythm — Claude knew it was pattern-matching and did it anyway, which means the fix is prompt-level, not model-level.

---

## Decision — prompt tuning IS warranted

The dominant issue is **variety enforcement**, not voice. Voice is holding at v5. The generator needs recent-post context that lets it see the pattern it's about to extend and hard rules that force it to break the pattern.

### Changes shipped in this PR

1. **`lib/social/db.ts` — `recentForContext`** now also returns `content_formats`, `accent_badges`, and `image_bgs` from the last 30 posts.
2. **`lib/social/post-generator.ts`**
   - `GeneratorInputs` accepts three new optional fields (`recentContentFormats`, `recentAccentBadges`, `recentImageBgs`).
   - `buildUserPrompt` renders three new sections in the user prompt so Claude can see the recent tail.
   - `SYSTEM_PROMPT` gains a **VARIETY ROTATION** section with 5 hard rules: no format 3x in a row, no dollar figure reuse, no display-template reuse, no image_bg 2x in a row, opener discipline.
   - Pre-submit checklist gains an 8th check: "Does this post BREAK the recent pattern?"
   - `PROMPT_VERSION` bumped from `2026-05-13.v5` → `2026-07-26.v6`.
3. **`app/api/social/fb-daily-generate/route.ts`** passes the new context fields.
4. **`scripts/test-post-generator.ts`** passes representative recent-context values so the test exercises the rotation prompt.
5. **`docs/product-thesis.md`** documents the **Variety rotation policy** as a locked constraint under "Content formats."

### What was NOT changed

- The v5 voice is untouched. This is refinement, not a voice pivot.
- `BLOCKLIST` unchanged. No new phrases rose to the "must ban" bar.
- The 5 content formats and their examples are unchanged.

### Expected effect

Next 7 days: format distribution should look closer to 2-2-1-1-1 across the five formats. Dollar figures should span a range. Display templates should visibly vary. `warm-gradient` should drop below 40% of image_bgs.

If the next audit (2026-08-02) still shows format monoculture, escalate — the rotation prompt isn't enough and we need a hard server-side reject (e.g. the route refuses to publish a post whose format matches the last 2).
