generator has collapsed onto one of the five locked formats. The other
four (`direct`, `math`, `brand-callout`, `objection-reframe`) appeared

The voice itself is on-thesis. The variety axis is not.

## Pattern analysis

1. **Anecdote is the local optimum.** Anecdote lets the model hit all
   three canonical pieces mechanically (city + product + $ amount +
   eligibility puncture + CTA). It's the safest format. Without a
   counter-pressure to rotate, Claude defaults here.

2. **The user prompt doesn't show Claude what formats it's been using.**
   `buildUserPrompt()` passes `recentAngleTags` and `recentDisplays`
   only. Claude has no signal about the format distribution and so
   can't self-correct toward under-used formats.

3. **Within `anecdote`, the template itself has narrowed.** Every
   caption opens "A regular mom in [City] [did everyday thing]…" or a
   close paraphrase. The system prompt's anecdote example uses exactly
   that opener, and Claude has copied it five times running. We need
   to call out template variety inside the format.

4. **No dead phrases slipped through.** BLOCKLIST is doing its job
   — nothing to add this week.

5. **Voice and vocabulary discipline is excellent.** "Regular moms,"
   "real money," "find out more," "get your cut," "no celebrity status"
   all land consistently. The v5 voice itself is locked in tight.

6. **Caption length:** 78–168 words. Healthy distribution, on-platform.
   No action needed.

7. **No CTAs missing momfluence.app.** All five end correctly.

## Prompt change proposed (this PR)

Refinement, not voice pivot. v5 voice unchanged.

**Edits to `lib/social/post-generator.ts`:**

1. Add optional `recentContentFormats?: string[]` to `GeneratorInputs`
   so the route handler can pass the last 7–14 days of format tags.
   Keeps the existing callers source-compatible (`route.ts`,
   `scripts/test-post-generator.ts`).
2. `buildUserPrompt` now renders a "recent formats" line when the array
   is provided, with the explicit instruction to rotate away from the
   over-represented format.
3. Add a new section in `SYSTEM_PROMPT` titled "FORMAT ROTATION (HARD
   RULE)" that:
   - Forbids using the same `content_format` more than 2 times in any
     rolling 7-post window.
   - Names `anecdote` specifically as the format the generator drifts
     into and tells Claude to bias *away* from it when in doubt.
   - Inside `anecdote`, requires varying the opener (don't always lead
     with "A regular mom in [city]…") and rotating cities.
4. Add a soft `image_bg` rotation hint so visuals don't stay
   monochrome.
5. Bump `PROMPT_VERSION` from `2026-05-13.v5` → `2026-05-24.v6`.

**Edit to `docs/product-thesis.md`:**

- Append a "Format rotation rule" note under "Content formats" naming
  the 2-out-of-7 cap and the anti-drift bias.

**Caller follow-up (out of scope for this PR, flagged for the human):**

`app/api/social/fb-daily-generate/route.ts` should be updated to query
`generation_metadata->>'content_format'` from the last 7 posts and pass
it as `recentContentFormats`. Until that lands, the new prompt
directive still helps because the rotation rule is in the system
prompt, but the recent-format signal won't be present in the user
prompt. Flagging in the PR body for the next routine.
