## Pattern analysis

### 1. Format monoculture (severity: high)

6/6 posts are `anecdote`. The v5 thesis defines FIVE content formats
explicitly as the variety axis, and the daily generator has produced ONE for
the entire audit window. This is the exact failure mode the format taxonomy
was designed to prevent. The Bayesian optimizer downstream cannot compare
formats without data across formats.

### 2. Anecdote-template rut (severity: high)

Displays across the six posts:

- "She named the tissues / in the conference hallway."
- "She named the bobby pins / backstage at the recital."
- "She named the shin guards / on the soccer sideline."
- "She named the kids' umbrella / in the drop-off line."
- "She named the board book / on the storytime rug."
- "She named the mittens / at the bus stop corner."

Five of six use the identical "She named the [X] / [preposition] the [Y]"
template. The rationale field in generation_metadata self-admits this — one
of them says the format was chosen to "continue the 'she named the ___'
visual rhythm." The generator is being told to avoid recent slugs but nothing
tells it to break the display *template*.

Caption bodies show the same pattern: "A regular mom in [City] was [doing
routine thing]. Another mom asked about [product]. She [named/told/dropped
the link]. N moms bought. She got paid $X." Every single caption fits this
mold.

### 3. Eyebrow monoculture (severity: medium)

5/6 eyebrows are permutations of "REAL MOM(S), REAL MONEY/MOMENT." The one
exception (07-28) says "TRUE STORY." No variety of tone.

### 4. Image visuals stuck in a rut (severity: medium)

4/6 warm-gradient, 2/6 navy-coral-gradient. Zero use of `coral`, `navy`,
`cream`, or `white-coral-ring`. Feed is visually monotonous.

### 5. Angle-tag suffix (severity: low)

All 6 angle_tags end in `-rec`. Cosmetic but reinforces the pattern.

### 6. Dead phrases (severity: none)

Zero dead-phrase hits. BLOCKLIST is holding.

### 7. Caption length distribution (severity: none)

Range 129–222 words, all comfortably within the 80–300 spec.

## Root cause

The generator sees `recentAngleTags` and `recentDisplays` in its user
prompt, and Claude is interpolating "more of the same *type*" rather than
"different type." There is no signal telling the model:

- What `content_format` values have been used recently
- That format rotation across days is a REQUIREMENT
- That a repeated headline template is itself a failure mode (even if the
  slug differs)

Missing signal → predictable model behavior. This is a prompt problem, not a
Claude problem.

## Prompt tuning proposed (see companion PR)

`lib/social/post-generator.ts` — bump to `2026-08-02.v6`:

1. Add **FORMAT ROTATION** section to SYSTEM_PROMPT: pick a format not used
   in the last 3 posts; if `recentContentFormats` shows an imbalance, break
   it.
2. Add **TEMPLATE FATIGUE** section: name the "She named the [X] at [Y]"
   anecdote template explicitly and forbid re-using it verbatim; when writing
   anecdotes, vary the sentence structure of the display.
3. Add **VISUAL VARIETY** hint on `image_bg` and eyebrow phrasing.
4. Add optional `recentContentFormats: string[]` field to `GeneratorInputs`
   (backward compatible — old callers keep working). When present, the user
   prompt lists the recent format distribution so the model can see the
   imbalance directly.
5. `buildUserPrompt` gets a paragraph that instructs the model to inspect
   the recent headlines for shared visual rhythm and break it.

**Not proposing:** additions to BLOCKLIST. No phrase-level dead phrases
slipped through this week. The rut is structural, not lexical, and a
BLOCKLIST entry like "she named" would kill legitimately good anecdote
writing.

Not a voice pivot — the v5 voice is holding perfectly. This is a
variety-enforcement tightening.
