## Pattern analysis

### 1. Format monoculture (CRITICAL)
5/5 anecdotes. The prompt hands Claude five formats and asks it to pick one; it
picks the most vivid one every single day. `recentDisplays` gets fed in but
`recentContentFormats` does NOT — the model has no explicit signal that it's
in a rut. Even if it did, the current prompt doesn't tell it to rotate.

### 2. Formula rut inside the format
Every anecdote follows the identical skeleton:
- Regular mom in [US city]
- [Kid-activity scene: back-to-school night / open house / picture-day drop-off / gymnastics viewing window / music class rug]
- Someone asks about a product
- She names it, "X moms wrote it down" / "texted the link"
- She got paid $[NUMBER]

Every display uses the pattern `"She named the [PRODUCT] / [location clause]."`
Five in a row. Anyone scrolling the Momfluence FB Page sees the same post
five days running with the product swapped out.

### 3. Number rut
4 of 5 posts use **$340** as the payout figure. The fifth uses $580. The
locked v5 example in the thesis uses $720. The model has anchored on $340.

### 4. Setting rut
Every scene is a child-activity scene at a school/class. Zero group-chat,
Nextdoor, Facebook Marketplace, PTA email, evening scroll, checkout line, or
non-parenting scenes — despite the thesis explicitly listing those as valid
anchored moments.

### 5. Visual rut
- `image_bg`: 4× `warm-gradient`, 1× `navy-coral-gradient`. Never `coral`, `navy`, `cream`, or `white-coral-ring` all week.
- `accent_badge`: 4× `$340`, 1× `$580`. Same rut.
- `eyebrow`: 4× a school moment ("BACK-TO-SCHOOL NIGHT", "OPEN HOUSE NIGHT", "PICTURE DAY, 7:42 AM", "TUESDAY, 10:47 AM"), 1× "REAL MOM, REAL MONEY".

### 6. City reuse
Charlotte appears twice in five posts.

### 7. Voice, vocabulary, dead phrases — all clean
- "regular moms" used correctly every post
- "real money" / "big bucks" used correctly
- "products and services" used correctly (Hulu/Disney+ in the mix)
- "find out more and get your cut" used correctly
- Zero BLOCKLIST hits
- No pain-point openers, no corporate register, no "everyday moms"

The v5 vocabulary lock is working. The v5 format-variety intent is not.

### 8. Retry noise
- 2 of 5 posts (gen-07-11 and gen-07-09) needed 2 attempts; gen-07-08 needed 3.
- Likely angle_tag near-duplicates or blocklist trips — the retries produced
  more anecdotes with different props. The retry loop isn't nudging toward
  format variety, only toward angle-slug uniqueness.

## Fix (this audit's prompt tune)

Non-negotiable at this point — the pattern is too obvious to leave. The change
is a **refinement, not a voice pivot** (voice compliance is 5/5; the pivot is
purely in format-selection logic).

Changes made in this PR:

1. `SYSTEM_PROMPT` gains an explicit **CONTENT-FORMAT ROTATION** section.
   Anecdote is powerful but must not be the daily default; the model is
   instructed to actively avoid the most-recent format and to pick from the
   4 others by default.
2. `SYSTEM_PROMPT` gains an **ANTI-FORMULA** callout inside the `anecdote`
   section: don't reuse $340; don't always use kid-activity scenes; vary the
   `[X moms wrote it down / she got paid]` scaffolding; not every anecdote
   needs an in-person scene.
3. `GeneratorInputs` gains an **optional** `recentContentFormats: string[]`
   field. If the caller passes it, the prompt renders the recent-formats
   distribution so Claude can see the rut. If the caller doesn't pass it
   (current state — `app/api/social/fb-daily-generate/route.ts` doesn't),
   the prompt's rotation directive still fires from the strengthened
   language alone. Follow-up: wire `recentForContext` in `lib/social/db.ts`
   to also return `content_formats` — outside this PR's allowed scope,
   flagged as a follow-up.
4. `PROMPT_VERSION` → `2026-07-12.v6`.
5. `docs/product-thesis.md` gets a short **Format rotation** subsection
   under "Content formats" clarifying that the daily generator is expected
   to rotate through the five textures, not ride one.

No BLOCKLIST additions — no dead phrases slipped through this week. Adding
`$340` or `wrote it down` to BLOCKLIST would be over-correcting: those aren't
dead phrases, they're just overused right now. Prompt guidance is the right
lever.

## Follow-ups (out of this PR's scope)

  the new optional prompt input stays empty and the rotation nudge relies
