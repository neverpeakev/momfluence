## 3. Pattern analysis

### 3a. Format monoculture (severity: CRITICAL)
Every published post for the last 26 days is `anecdote`. The four other locked formats — `direct`, `math`, `brand-callout`, `objection-reframe` — have not appeared in over a month. The v5 thesis explicitly requires format variety as the primary variation axis ("The MESSAGE is fixed... The variation across posts is the FORMAT"). We are running with 1/5 of the intended surface area.

### 3b. Display-line rut (severity: HIGH)
Every one of the 26 posts opens its display headline with `"She named the ___ / at [location]"`. This visual rhythm has been captured verbatim across a month. Even inside the anecdote format, this is one specific POV out of many that anecdote allows.

### 3c. Setting/geography rut (severity: MEDIUM)
5 of 6 this week are set in Cincinnati; the 6th is Dayton or Portland. Every single anecdote of the last 4 weeks is set at a school-adjacent event (graduation, picture day, PTA, scout meeting, dentist waiting room, cheer practice, band concert, art class volunteer table). The reader profile in the thesis is broader — group chats, Nextdoor, mom Facebook groups, neighborhood marketplace — but that surface has vanished from the anecdotes.

### 3d. Payout figure clustering (severity: LOW)
$310, $312, $312, $340, $340, $340 across six posts. Reads as invented and formulaic. Anecdote-format worked examples are fine per the thesis, but the tight $310–$340 clustering telegraphs template rather than variety.

### 3e. Opener compliance (severity: MEDIUM)
Only 1 of 6 posts uses a casual opener from the locked list. The other 5 default to `"A regular mom in [City]..."` which is fine narrative prose but skips the "smart friend texting" hook the thesis makes locked.

### 3f. Dead-phrase hits (severity: NONE)
Zero. BLOCKLIST is holding. Voice guardrails on vocab are also holding — `regular moms`, `real money`/`big bucks`, `get your cut`, `find out more` all present.

### 3g. Angle_tag deduping works, but is the wrong safeguard
The generator dedupes by exact `angle_tag` slug, so it keeps producing thematically identical posts under distinct slugs (`kindergarten-graduation-tissue-pack-rec` and `school-picture-day-comb-rec` are structurally the same post). Deduping needs to move up a level to `content_format` and to display-pattern shape.

---

## 4. Root cause

The generator does not see its own recent format distribution. `recentForContext` in `lib/social/db.ts:52` only fetches `angle_tag` and `display` — it never reads `generation_metadata.content_format`. Claude picks a format on each run, and once anecdote worked (didn't hit blocklist, distinct angle slug), the pattern has silently self-reinforced for a month.

Neither the SYSTEM_PROMPT nor the user prompt currently instructs Claude to look at recent formats and rotate. The "5 formats are the variety axis" instruction is in the prompt but there is no feedback signal telling the model it has drifted.

---

## 5. Prompt tuning applied (v6)

Changes on branch `claude/prompt-tune-2026-08-23`:

1. **`lib/social/db.ts`** — `recentForContext` now also returns the last 30 `content_format` values from `generation_metadata`.
2. **`lib/social/post-generator.ts`**:
   - `GeneratorInputs` gains `recentContentFormats: string[]`.
   - `buildUserPrompt` renders a `# RECENT CONTENT FORMATS` block showing the last 15 formats used, so Claude can see the distribution directly.
   - `SYSTEM_PROMPT` adds a **# FORMAT ROTATION** section requiring the model to pick a format that hasn't run in the last 3 posts (with tiebreak preference for a format missing entirely from the recent window).
   - `SYSTEM_PROMPT` adds a note flagging the "She named the ___" display pattern as retired for now; the model must pick a fresh display shape.
   - `BLOCKLIST` gains `"she named the"` (case-insensitive substring) so a display-line regression triggers a retry rather than shipping. A soft-cool-down at the prompt layer + a hard block at the validation layer.
   - New retry hint injected on subsequent attempts includes explicit format-rotation guidance.
3. **`app/api/social/fb-daily-generate/route.ts`** — passes the new `recentContentFormats` field through.
4. **`PROMPT_VERSION`** bumped to `2026-08-24.v6`.
5. **`docs/product-thesis.md`** — new subsection "Format-diversity target" under "Content formats" naming the rotation rule explicitly (target: each of the 5 formats appears at least once every 7 days; no single format >3 of any consecutive 7-day window).

None of the v5 voice locks were touched. This is a variety fix, not a voice pivot.
