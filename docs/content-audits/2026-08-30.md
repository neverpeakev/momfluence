## Pattern analysis

### 1. Format collapse (critical)

6/6 = `anecdote`. Root cause: the previous generator prompt tagged
formats but didn't give Claude any signal about which formats had been
recently used. The `angle_tag` variety filter is bypassed with trivial
noun swaps ("robotics-club-competition-zip-ties-rec" vs.
"chess-club-tournament-timer-battery-rec") — the actual writing is
identical. Format tag was never part of the "recent" context.

### 2. Structural sameness inside the anecdote (critical)

Every post's caption follows:

> "A regular mom in [City] was [doing mundane thing] when [triggering
> moment]. [Product recommendation]. [N] moms bought. She got paid $[X]
> for it."

Fresh nouns, identical bones. The thesis calls for anecdote to be a
texture, not a Mad Libs template.

### 3. Fabricated-testimonial drift

Six invented moms, six invented cities (Ohio, Des Moines, Cincinnati,
Columbus, Tulsa, Fort Wayne), six specific $ payouts. The thesis
explicitly warns: *"Never quote $/day or $/week as a promise — only show
worked examples."* These now read as customer testimonials, not
worked examples. That's an FTC-adjacent concern and it's also a trust
concern (readers who notice the pattern will suspect the moms are
composites — because they are).

### 4. Dollar-amount recycling

$312, $340, $340, $312, $184, $340. Three of six use $312 or $340.
Small pool. Reads as bot-picked.

### 5. Image_bg lock-in

`warm-gradient` used 4/6. Only two other bgs touched (`cream`,
`navy-coral-gradient`). Six format choices available, two used. Visual
week is monochromatic.

### 6. Vocabulary and blocklist compliance is clean

Zero dead phrases hit. Zero blocklist hits. "Regular moms" used
consistently. "Big bucks" / "real money" used. "Find out more" +
"get your cut" CTA used consistently. **This part of v5 is working.**

The problem is not the vocabulary — it's the structure above the
vocabulary.

## Prompt tune (v5 → v6)

Bumping `PROMPT_VERSION` to `2026-08-30.v6`. Changes:

1. **New signal into the prompt: `recentContentFormats`.**
   `db.ts::recentForContext` now also returns the last N `content_format`
   tags from `generation_metadata`. Cron passes them to
   `generateDailyPost`.

2. **New "RECENT FORMAT MIX" section in the user prompt.** Counts the
   last-7 formats, flags anything appearing ≥3× as **OVER-USED** and
   anything missing as **UNDER-USED**. Instructs Claude to rotate away
   from the dominant format.

3. **New "WEEKLY VARIETY IS A HARD REQUIREMENT" section in the system
   prompt.** Codifies two axes:
   - Format rotation (anecdote is a texture, not a fallback;
     brand-callout / objection-reframe are under-used in general).
   - Fresh openers within a format (specifically: don't repeat the
     "A regular mom in [City] was [doing thing]..." + specific $ receipt
     template on consecutive days).

4. **Reinforces the thesis "worked examples, not testimonials"
   distinction** — the invented-mom-in-city pattern was drifting into
   fabricated-testimonial territory.

5. **Added check #8 to the pre-submit checklist** — "Does the chosen
   format break the recent-format streak, and does the opener/structure
   differ from recent posts (not just the noun)?"

### What was NOT changed

- The v5 voice remains locked. This is a **refinement**, not a pivot.
- The BLOCKLIST is unchanged — no new dead phrases slipped through this
  week. The failure is structural, not phrase-level.
- The 5 content formats and canonical spine are unchanged.

### Thesis doc updated

Added a "Weekly format rotation (added 2026-08-30)" subsection under
"Content formats" that explicitly names the rules the new prompt hint
enforces. This keeps the thesis and the generator in sync.

## Recommendations for the human reviewer

1. **Merge the prompt tune this week.** Every day this stays live, another
   near-identical anecdote publishes.
2. **Watch next week's audit.** If the format-mix hint alone doesn't
   break the anecdote streak, consider a hard rotation constraint
   (e.g., "your chosen format must not equal any of the last 2 formats").
3. **Consider retiring the invented-city + invented-check anecdote
   sub-template.** The anecdote format is fine; the specific
   "she got paid $X" fabricated-testimonial variant is the risky version.
   The thesis's own anecdote example ("A regular mom in Indianapolis…
   $720") set this pattern — if it's ok for the *thesis* example, we
   should say so explicitly; if not, we should replace that example
   with an anchored-past-moment or aggregate-worked-example instead.
4. **The optimizer dashboard "by content format" rollup will be useless
   this week** — every row is anecdote. Give the tune a few days before
   reading it.
