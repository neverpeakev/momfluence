## 4. Pattern analysis

### 4a. Content-format monoculture (severity: HIGH)

30-day query: **27 of 27** published posts are `anecdote`. Not a bad week — a systemic bug. The prompt tells Claude to pick from five textures and gives beautiful gold-standard examples of each. But Claude has been picking anecdote every single time.

**Root cause:** the user prompt hands Claude `recentAngleTags` and `recentDisplays` — never `recentContentFormats`. Claude has no signal to rotate. And the anecdote example in the system prompt is by far the most vivid ("A regular mom in Indianapolis…"), so it's the most imitable. Without a counter-signal, the model reverts to what's easy to write.

**Fix (in the PR):** pipe `content_format` from `generation_metadata` through `recentForContext` → `GeneratorInputs.recentContentFormats` → user prompt. Show Claude the distribution AND the under-represented formats explicitly. System prompt now has a `⚠ FORMAT ROTATION IS MANDATORY` section citing the 27/27 finding.

### 4b. Headline-template reuse (severity: MEDIUM)

All 6 display headlines use the identical syntactic template:
> "She named the **[X]** / **[in|on|at]** the **[Y]**."

That is not variety — that's one Mad Libs. Fix in PR: added CHECK #9 telling Claude to spot recent syntactic templates and rewrite.

### 4c. $340 over-repetition (severity: MEDIUM)

Four of six posts use the exact same "$340" payout figure. When she scrolls the Page and sees $340 in the corner four days out of six, it reads as fake. Fix in PR: added CHECK #11 with a menu of alternative figures.

### 4d. Tagline overuse (severity: MEDIUM)

"Real moms. Real money. Real easy." appears verbatim in 4 of 6 posts. Thesis says "Use selectively — maybe 1 in 4 posts. Never every post." Real ratio right now: 67%. Fix in PR: added CHECK #10.

### 4e. Voice, vocabulary, dead-phrase compliance (severity: NONE)

- Voice — all 6 read as smart-friend, conversational. Clean.
- Vocabulary — "regular moms," "real money," "big bucks," "products and services," "get your cut" all used correctly. Clean.
- Dead phrases — zero BLOCKLIST hits. Clean.

### 4f. Visual (image_bg / accent_badge) diversity (severity: LOW)

- `image_bg`: `warm-gradient` in 5/6 posts, `cream` in 1. Never `coral`, `navy`, `navy-coral-gradient`, or `white-coral-ring`. Not addressed in this PR — deferring until format rotation lands to see if it self-corrects.
- `accent_badge`: five badges are `$340` or `$312`. Same story as 4c — self-corrects once dollar-figure variety is enforced.

## 5. Decision: prompt tuning warranted

**Yes.** Pattern 4a alone is a systemic bug — one of the five textures the thesis lists has been used 100% of the time for a month. Patterns 4b–4d are second-order symptoms of the same underlying issue (Claude locking into a single template because there's no counter-signal). All addressed in one PR.

**Changes shipped:**

1. `lib/social/db.ts` — `recentForContext` now also returns `content_formats[]` from `generation_metadata.content_format`.
2. `lib/social/post-generator.ts` — `GeneratorInputs` gains optional `recentContentFormats`; `buildUserPrompt` renders format distribution + names the under-represented format(s) explicitly; SYSTEM_PROMPT adds `⚠ FORMAT ROTATION IS MANDATORY` section citing the 27/27 finding; CHECK list expands from 7 to 11 items (format rotation, headline-template reuse, tagline cadence, dollar-figure variety).
3. `app/api/social/fb-daily-generate/route.ts` — passes `recentContentFormats` through.
4. `scripts/test-post-generator.ts` — includes `recentContentFormats` so the dry-run also exercises the new logic.
5. `docs/product-thesis.md` — one paragraph added under "Content formats" stating rotation is mandatory, not aspirational.
6. `PROMPT_VERSION` bumped: `2026-05-13.v5` → `2026-07-05.v6`.

**Not shipped (deliberate):**
- Voice is untouched. This is not a voice pivot.
- BLOCKLIST is unchanged. Nothing in the week's posts hit or should hit the BLOCKLIST; adding "she named the" as a blocklist entry would be too narrow (blocks a phrasing, not a bad idea).
- Visual (`image_bg` / `accent_badge`) diversity guardrails — deferred to next week. Best to change one thing at a time.
