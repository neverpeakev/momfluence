Claude's response was truncated mid-`caption` value on all three attempts, so `JSON.parse` always failed. No row was ever inserted (the failure is in stage=`generate`, before `insert_pending`).

## Root cause
`lib/social/post-generator.ts` set `MAX_TOKENS = 1500`. The schema allows captions up to 2000 chars (~600 tokens) and Opus 4.7 appears to be running close to the limit when it picks the longest format ("anecdote" with a fully-fleshed scene). 1500 tokens covered the smaller fields but ran out at the start of `caption`.

## Fix
Bumped `MAX_TOKENS` to 4000 in `lib/social/post-generator.ts`. PR: https://github.com/neverpeakev/momfluence/pull/CLAUDE_PR (branch `claude/fix-content-cron-2026-06-25`).
