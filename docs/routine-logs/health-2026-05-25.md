## Diagnosis
Same root cause as PR #88: **Meta Graph API v20.0 was sunset on 2026-05-21**. `app/api/social/fb-daily-generate/route.ts:39` and `app/api/social/ig-mirror/route.ts:40` still pin `META_API_VERSION = "v20.0"` on main.

For 05-23 and 05-24 Meta auto-routed FB publish + IG container POST past the sunset version, so a row was inserted and FB succeeded; only the IG container status-poll failed. Today the failure has crept earlier in the chain — most likely the `fetchPageAccessToken` call (`GET /me/accounts`) or the `recent_context`/`generate` step now fails under v20.0, before `insertPending` runs. Without the row insert, the `catch` block in `route.ts:209` has nothing to mark failed, so the DB stays empty.

Vercel runtime logs MCP timed out without returning entries (same observability gap PR #88 hit yesterday) — diagnosis is from DB state + sunset timing + code path, not direct log evidence.
