## Diagnosis (unchanged from prior 10 sessions)

`app/api/social/ig-mirror/route.ts` has three silent early-return paths that
return HTTP 200 with `ok:false`, write nothing to the row, and emit no log:

1. `META_MARKETING_API_TOKEN` / `META_FB_PAGE_ID` missing
2. `fetchPageContext` throws (token expired, missing `instagram_basic` scope,
   IG account unlinked, Graph API version sunset)
3. `listPendingIgMirror` returns empty

Today's <1s return + 9 truly-pending rows means we hit (1) or (2). Without the
observability patch in PR #114 we cannot see which.
