## Why the failure is silent
`app/api/social/ig-mirror/route.ts` had three pre-loop early-return paths that returned HTTP 200 with `{ok:false, message:"..."}` and no `console.error`, and — critically — **did not mark pending rows as `ig_failed`**:

1. Missing `META_MARKETING_API_TOKEN` / `META_FB_PAGE_ID` env vars
2. `nothing to mirror` (legitimate)
3. `auth/page-context: ...` — the `/me/accounts` or `/{pageId}?fields=instagram_business_account` call fails

Path (3) is the near-certain cause here. FB posting uses the same `META_MARKETING_API_TOKEN` on `/me/accounts` and still works daily, so the user token is not expired. The IG-specific step is `GET /{pageId}?fields=instagram_business_account` — if that returns no `instagram_business_account` field, the code throws `No Instagram Business Account linked to FB Page {pageId}`. This matches a Meta-side change on ~2026-05-27: **the IG Business account link to the FB page was severed, or the token lost the `instagram_content_publish` / `instagram_basic` scope**.

Vercel runtime logs at 14:15:08 UTC show only `GET /api/social/ig-mirror 200` with no log line body — consistent with the silent early-return.
