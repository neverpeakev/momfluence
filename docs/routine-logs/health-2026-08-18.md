# Content cron health — 2026-08-18

**Status:** FB cron failed at 14:01:36 UTC. No row inserted for today.

## Root cause

`generateDailyPost` retried 3× and failed identically each time with
`not valid JSON`. Vercel runtime log shows the raw response starting:

```
{
  "angle_tag": "art-class-pickup-smock-rec",
  ...
  "display": "She named the paint smock
     at art class pickup.",
```

The model emitted a literal newline (0x0A) inside the JSON `display`
string value. `JSON.parse` rejects control chars in string literals, so
every attempt bounced out at the parse step. The prompt explicitly tells
the model `display` "can use \n for line break" — occasionally the model
takes that as "emit a real newline" rather than the two-char escape.

Because the failure happens before `insert_pending`, no row exists in
`generated_posts` for today. Yesterday's row (2026-08-17) is still stuck
at `fb_published` (IG mirror side is a separate, longer-standing outage
tracked in earlier health logs / PRs #194, #195, #197).

## Fix

PR: claude/fix-content-cron-2026-08-18 — adds
`escapeControlCharsInJsonStrings` and a one-shot JSON-parse retry that
runs the model output through it when the first parse fails. Preserves
already-escaped `\n` and whitespace outside strings.

## Not fixed here

- IG mirror still not publishing (token / linked-account issue tracked
  separately). Today's fix restores FB posts only.
- Today's FB post will still be missing until the next scheduled run
  (2026-08-19 14:00 UTC) unless the cron is manually re-triggered after
  the fix ships. Backfilling today by hand is at the operator's discretion.
