## Fix applied (PR)
PR (draft): https://github.com/neverpeakev/momfluence/pulls — branch `claude/fix-content-cron-2026-06-09`

This does **not** fix the underlying IG publishing problem (which needs Meta-side investigation). It fixes the observability gap that's been hiding it for 12 days:

1. `lib/social/db.ts` — new `noteFailure(id, stage, message)` that writes `error_message` + `errored_at` without flipping status to a terminal `_failed`. Rows stay `fb_published` and remain retryable on the next cron run.
2. `app/api/social/ig-mirror/route.ts` — when env vars are missing or `fetchPageContext` throws, call `noteFailure` for every row in the current `pending` batch before returning. Also reorders so `listPendingIgMirror` runs first (it's cheap and lets the env-var path also report).

After this deploys, the next IG mirror cron run will write the real error into `generated_posts.error_message` for every pending row, and we'll know exactly which Meta call is failing.
