## Root cause (best inference)
`app/api/social/ig-mirror/route.ts` has three code paths that return 200 with no `console.*` output and no DB write:
1. Missing env vars (`META_MARKETING_API_TOKEN` / `META_FB_PAGE_ID`)
2. `listPendingIgMirror` returns empty
3. `fetchPageContext` throws inside the early `try { ... } catch` block

Vercel runtime logs for `14:15:08 GET /api/social/ig-mirror → 200` show zero stdout/stderr beyond the access line, on today and every prior day inspected. FB cron uses the same `META_MARKETING_API_TOKEN` successfully (it calls `/me/accounts` and stops), so path 1 and the `/me/accounts` half of path 3 are ruled out. The 22 matching rows rule out path 2. That leaves path 3's second leg: `fetchPageContext` querying `/{pageId}?fields=instagram_business_account`. Most likely the page-access token is missing one of `instagram_basic` / `instagram_content_publish`, or the IG Business Account linkage isn't readable with the current token's scopes — but the swallow-without-logging means we can't see which.
