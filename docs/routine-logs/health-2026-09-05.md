## Why IG mirror returns 200 without doing anything
`app/api/social/ig-mirror/route.ts:178-192` catches `fetchPageContext`
failures and returns `{ok:false, message:"auth/page-context: ..."}` with
HTTP 200. It does NOT mark the pending rows as `ig_failed`. So each day
the row survives, the query at `lib/social/db.ts:153-165` keeps returning
the growing backlog, and Meta Graph API returns
`No Instagram Business Account linked to FB Page 1086292991223812`
every time. Nothing surfaces in logs because the failure never throws
and the endpoint response body isn't sampled by log-scraping.
