IG status check → 400: {"error":{"message":"Authorization Error","code":100,

Error subcode 33 = "This object does not exist, cannot be loaded due to missing permissions, or does not support this operation." Interpreted here: the Page-scoped access token cannot read the newly-created IG media container — the token most likely lost `instagram_basic` / `instagram_content_publish` scope, or the FB Page ↔ IG Business Account link was broken.

## Why the failure went silent

`app/api/social/ig-mirror/route.ts` has three pre-loop early-return branches (`env missing`, `nothing to mirror`, `auth/page-context`) that all return 200 with an error string only in the JSON body. **None of them write to `console.error`**, so Vercel Runtime Logs show only the middleware entry (`GET /api/social/ig-mirror 200 [info/edge-middleware]`) with no visible reason.

The most likely current branch is `auth/page-context` — `fetchPageContext(userToken, pageId)` either

1. can't find the Page in `/me/accounts` (token scope loss), or
2. finds the Page but `instagram_business_account` is missing from `/{pageId}?fields=instagram_business_account` (link broken or missing `instagram_basic`).

Direct SQL confirms `listPendingIgMirror` should be returning ≥10 rows every day, so "nothing to mirror" is not the branch. FB cron uses the same `META_MARKETING_API_TOKEN` on the same day and succeeds, so the token exists and can list pages — pointing at IG-specific scope or link, not general token failure.

## Fix landed

PR: `claude/fix-content-cron-2026-07-10` (see repo).

`app/api/social/ig-mirror/route.ts`:
1. `console.error` on the env-missing early return.
2. `console.log` the `pending.length` after `listPendingIgMirror` so future runs distinguish empty-queue vs. auth failure.
3. `console.error` on the auth/page-context early return, including the count of stuck rows.

That's observability-only — it does not fix the underlying Meta auth issue but will make the next cron run reveal the exact `auth/page-context: <msg>` string so the human owner can regenerate the token / re-link IG.
