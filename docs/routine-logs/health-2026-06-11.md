## Fix

PR: `claude/fix-content-cron-2026-06-11` — `app/api/social/ig-mirror/route.ts`

1. `console.error` on every failure branch (auth, env, page-context, per-row publish, mark-failed fallthrough).
2. Non-2xx status codes for non-recoverable failures (500 for env missing, page-context throw, and any per-row failures in the batch) so the Vercel cron health view actually flags them.
3. `console.log` summary on success / "nothing to mirror" + per-batch slug list so each run is traceable in runtime logs.
