## Root cause

`lib/social/post-generator.ts` blocks `"here's the thing"` in the
`BLOCKLIST` array (line 99), but the **DEAD PHRASES** section of the
`SYSTEM_PROMPT` only names `"real talk," "hot take," "let's be honest"`
as overused openers — it does not list `"here's the thing"`. Claude
never saw a first-class instruction to avoid it, kept reaching for it
as a natural connector, and the retry note only surfaces the single
most recent error, so all three attempts hit the same phrase.

## Fix

PR **claude/fix-content-cron-2026-07-07** does two things:

1. Adds `"here's the thing"` to the DEAD PHRASES bullet in
   `SYSTEM_PROMPT` alongside the other overused openers, so Claude sees
   the ban in-context on attempt 1 (not just as a raw post-hoc reject).
2. Rewrites the RETRY NOTE to accumulate every prior attempt's failure
   reason (`priorErrors[]`) instead of only the most recent one. When
   attempt 2 fails, attempt 3's prompt now quotes both banned phrases,
   which closes the "Claude fixates on one phrase" failure mode.
